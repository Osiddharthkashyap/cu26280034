# Lab Sheet 09 — CRUD Operations

Contains 20 standalone Python solutions. List/dictionary examples operate in memory for the duration of the program. File-based CRUD uses `student_records.json`; database examples use the shared SQLite file `crud_students.db`. Run Q11 before Q12–Q20 (Q20 also creates the table automatically). Python 3 and its built-in `sqlite3` module are sufficient.

Run with `python Q<number>-<file_name>.py`.
