# MCA First Semester Lab Sheets and Code

This repository contains code, lab sheets, practical assignments, and supporting files for the first semester of the Master of Computer Applications (MCA) programme at COER University, batch 2026-2028.

## Repository Structure

Each course is maintained in its own top-level directory. Course directories may include lab sheets, source code, assets, and course-specific documentation.

```text
<COURSE_NAME>/
  lab_sheet_01/
  lab_sheet_02/
  ...
```

## Courses

This repository is intended to include material for all first-semester MCA courses. The available course directories may grow as lab work and assignments are added.

## Usage

Open the relevant course directory and then select the required lab sheet or source file. Refer to a course directory's README, when available, for course-specific details.
