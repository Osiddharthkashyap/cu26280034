# Web Designing

HTML and CSS laboratory assignments for the Master of Computer Applications course.

## Lab Sheet 1

`lab_sheet_01` contains `q1.html` through `q25.html`, covering HTML structure, text formatting, lists, images, tables, and forms.

## Lab Sheet 2

`lab_sheet_02` contains `q1.html` through `q22.html` and their matching `q1.css` through `q22.css` stylesheets. The exercises cover form styling, CSS layouts, validation, responsiveness, and accessibility.

Open any HTML file in a web browser to view its output.
