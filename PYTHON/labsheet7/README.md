# Lab Sheet 07 — File Handling

Contains 30 standalone Python solutions, named `Q<number>-<file_name>.py`.

Run with Python 3: `python Q1-create_text_file.py`.

Most text programs use `sample.txt`; number processing uses `numbers.txt`; CSV programs use `students.csv`. Create/run the relevant setup program first (Q1 or Q21). Q20 expects `file1.txt` and `file2.txt`; Q30 expects `students.csv` and `students_extra.csv` with matching headers.
